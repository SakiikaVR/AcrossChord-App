# アクロスコード (AcrossChord)

モバイル向けのコード譜作成・閲覧アプリです。
サーバー不要・アカウント不要で、データはすべて端末内 (`localStorage`) に保存されます。
外部ライブラリには一切依存しない、単一 HTML ファイルのアプリです。

v2.0 で全面刷新し、Android アプリ (APK) としてリリースしています。

## 📦 ダウンロード (Android)

**[Releases](https://github.com/SakiikaVR/AcrossChord-App/releases/latest)** から最新の APK をダウンロードしてインストールしてください。

- 動作環境: Android 9.0 (API 28) 以降
- APK は [さきいかビルダー](https://github.com/SakiikaVR/Sakiika-Builder) でビルドしています
- マイク権限はクロマチックチューナー機能でのみ使用します

## 機能

### コード譜ライブラリ
- 曲の一覧表示（五十音・アルファベットのインデックス付き）
- 曲名・アーティスト名・本文でのインクリメンタル検索
- 長押しで複数選択モードに入り、まとめて削除
- プレイリストの作成・曲の追加/削除・まとめて削除

### コード譜エディタ（ChordPro 形式と互換）
- 記法は [ChordPro](https://www.chordpro.org/) 形式と互換性があります。他の ChordPro 対応アプリで作成した譜面をそのまま貼り付けて利用できます
- `{title: 曲名}` `{artist: アーティスト}` `{key: C}` でメタ情報を指定（`{t:}` `{st:}` `{k:}` などの短縮形にも対応）
- `{c: コメント}` でコメント行を表示
- 歌詞中に `[C]` `[Am7]` `[Eb/G]` のようにコードを埋め込み
- `[N.C.]` や `[----]` などの非コード記号にも対応

### コード譜ビューア
- 歌詞の上にコード名を配置して表示
- **コード名をタップするとギターの押さえ方（ダイアグラム）をポップアップ表示**
- ダイアグラムを常に表示するモードも選択可能
- 表示モード切替: コード名 / パワーコード (5th) / NNS（度数）表記
- Key の変更・Capo (0–11) 指定による自動移調
- シャープ (#) / フラット (♭) 表記の切替
- ズーム (50%–300%)
- 速度調整つきオートスクロール
- 「戻る」操作に対応した画面遷移

### ギターチューニング対応
コードダイアグラムは選択中のチューニングに合わせて自動変換されます。
- Standard / Drop D / 半音下げ / Drop C# / 全音下げ / Drop C / Drop B

### クロマチックチューナー
- マイク入力から自己相関法でピッチを検出
- 音名・周波数・セント単位のズレをメーター表示

### テーマ / カスタマイズ
- ダーク / ライトテーマ切替
- アクセントカラーの変更

### データ管理
- ライブラリを JSON ファイルとしてエクスポート
- JSON ファイルからのインポート（マージ）
- 全データ削除

## 使い方

1. アプリを起動し、右下の **＋** ボタンで新規曲を作成
2. エディタに以下のように入力して保存:

```
{title: ふるさと}
{artist: 文部省唱歌}
{key: C}

[C]うさぎ[F]おいし[G7]かのや[C]ま
```

3. ライブラリから曲をタップすると、コード付きで表示されます

ブラウザで使う場合は `index.html` をそのまま開くだけでも動作します。

## 仕組み

- アプリ本体は単一の HTML ファイル ([index.html](index.html)) で、外部ライブラリに依存しません
- データの保存先は端末内の `localStorage` です（サーバーへの送信はありません）
- APK は [さきいかビルダー](https://github.com/SakiikaVR/Sakiika-Builder) により、この HTML を WebView アプリとしてパッケージしています（ビルド設定: [sakiika.json](sakiika.json)）
